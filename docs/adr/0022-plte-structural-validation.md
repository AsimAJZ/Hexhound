# PLTE is structurally validated like tRNS

PLTE is not a mere presence flag. This PNG slice checks CRC, at most one PLTE, order relative to IHDR/IDAT/tRNS, and specification payload shape (length divisible by 3, 1–256 entries). Type-3 tRNS length is defined against that palette size. Palette aesthetics are not interpreted.
